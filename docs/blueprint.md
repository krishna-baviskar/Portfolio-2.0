# **App Name**: CodeCanvas Portfolio

## Core Features:

- Interactive 3D Canvas: Dynamically rendered 3D particle and shape environment to enhance visual engagement. Adjust particle speed and shape complexity.
- Animated Navigation: Smooth scrolling and animated transitions between portfolio sections to enhance user experience.
- Responsive Layout: Ensure optimal viewing experience across devices with a fully responsive design.

## Style Guidelines:

- Primary color: Deep Indigo (#4B0082) to reflect intelligence and sophistication.
- Background color: Very dark desaturated indigo (#12031F), nearly black.
- Accent color: Violet (#8A2BE2) for highlighting interactive elements and calls to action.
- Headline font: 'Space Grotesk', sans-serif. Body font: 'Inter', sans-serif. The Space Grotesk font will be used for headlines and Inter for body text
- Use a set of modern line icons from Lucide to represent skills and project categories.
- Emphasize a clean, full-screen layout with clear section divisions to highlight different aspects of the portfolio.
- Subtle animations and transitions on hover effects to create an engaging and dynamic user experience.
